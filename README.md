# TableNod website

Open the homepage: https://ilovecpu.github.io/TableNod-Web/

This repository contains only the generated public website files for GitHub Pages.
Application source and development history are maintained separately.

The homepage links to the live restaurant QR calling web app at
https://tablenod-restaurant.dj-kim-1902.chatgpt.site/app
Staff phone/tablet browsers receive guest requests after location verification.
Five tables are free. Paid plans, LCD firmware and native/watch apps remain planned.

The server and database are hosted separately; GitHub Pages serves the homepage.
